- 第1回（素のLLM）とエージェントの回答の違い：
第１回では、レベル２の「実装」を、モデルは「応用」と答えたが、今回、エージェントを用いた結果は、用語集に記載している内容と同じことを答えた。
- `--trace` で見えたツール呼び出し（ツール名と引数）：
　[tool call]   search_glossary({'query': 'LoRA'})
　[tool call]   search_glossary({'query': 'QLoRA'})
- 1つの質問での LLM 呼び出し回数（`requests`）：２回
- 追加したツールと、docstring に書いた説明：
　ツール名：make_quiz(lecture: int)
　docstring の説明：
　　指定した回の用語から１つ選び、
　　確認問題と答えを返す。

　　「第２回の確認問題を出して」のように、
　　復習用の問題を求められたときに使う。
## 宿題

- 取り組んだレベル：基礎
- やったこと：
　tools.py: make_quiz の実装
　agent.py: make_quiz がモデルで実行できるように登録
　make_quiz の引数に０が入った場合の挙動確認
- 結果：　uv run python -m app.agent --trace " 第２回の内容から確認問題を１問出して"とターミナルに打ち込んで実行すると、glossay.jsonから第２回の用語の１つを選んで問題例と回答を出力するようになった。
　第７回の内容から、とコマンドで打つと、
『　現在、第7回の講義内容は用意されていないため、確認問題を作成することができません。

現在用意されているのは以下の回ですので、こちらの回から問題をお出しすることも可能です。どの回の問題をご希望でしょうか？
- 第1回
- 第2回
- 第3回
- 第5回

（関連する回：第7回）
』と出力された。
- 気づき・疑問：
上記の「第７回」の質問の際に、trace には、
[tool return] make_quiz -> 第7回の用語が見つかりませんでした。…
と出力された。これはmake_quizに書いた通りだが、本文では、
『　現在、第7回の講義内容は用意されていないため、確認問題を作成することができません。』
『　現在用意されているのは以下の回ですので、こちらの回から問題をお出しすることも可能です。どの回の問題をご希望でしょうか？』
と出力されている。ここまで丁寧に回答するとは思わなかった。make_quizの返り値だけで、agent.pyは更問いまで回答してきたことに驚いた。モデル内の回答と、実際に出力される回答が異なることが分かった。
